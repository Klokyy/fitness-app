# Fitness offline

Offline verze osobní tréninkové appky (plán dne + zápis sérií). Instaluje se jako PWA a funguje bez internetu.

- V repozitáři je **jen kód**. Data (plán, zápisy) jsou uložená jen v prohlížeči telefonu a přenáší se ručně přes schránku.
- Postaveno z `app-index.html` skriptem `build_pwa.py` (zdroj mimo repozitář).
